# GameLock Shop 🎮

Um website e-commerce moderno e responsivo para catálogo e venda de jogos, com vitrine interativa e suporte a carrossel dinâmico.

## 📁 Estrutura do Projeto

```text
site_de_compras/
├── index.html              # Página principal da loja
├── css/
│   └── style.css           # Estilos e responsividade
├── js/
│   └── main.js             # Lógica interativa do carrossel
├── assets/
│   └── images/             # Imagens e ícones dos produtos
└── README.md               # Documentação do projeto
```

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estrutura semântica e acessível.
- **CSS3**: Layout moderno com Flexbox, gradientes e animações suaves.
- **JavaScript (ES6+)**: Controle dinâmico do carrossel da vitrine com cálculo responsivo.

## 🛠️ Como Visualizar

Basta abrir o arquivo `index.html` em qualquer navegador web ou hospedar diretamente no **GitHub Pages**.
